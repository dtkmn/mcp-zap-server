  <p><strong>Available release: v0.17.1.</strong> Linux AMD64 and ARM64 images are published on Docker Hub and GHCR. The <a href="https://github.com/dtkmn/mcp-zap-server/releases/tag/v0.17.1">GitHub release</a> includes the Claude Desktop 0.1.0 bundle, setup guide and checksum files. Read the <a href="https://github.com/dtkmn/mcp-zap-server/blob/v0.17.1/docs/releases/RELEASE_NOTES_0.17.1.md">tagged release and upgrade guide</a> before changing an existing installation.</p>

  <p><strong>Release and source behavior differ.</strong> The first-run Docker commands use v0.17.1: scans start directly with the default local settings. Optional queue controls and the former expert tools remain available. In current source, every new crawl and active scan runs through the job queue. The feature and operations pages below describe current source unless labeled for a release; use the <a href="https://github.com/dtkmn/mcp-zap-server/tree/v0.17.1/docs">tagged v0.17.1 documentation</a> for the released runtime. Its migrations are V1–V8; current-source launch-safety guidance includes V9.</p>

  <p>The earlier v0.17.0 GitHub release remains incomplete: its Desktop downloads are absent and its image-release workflow did not complete. Registry discovery is separate from image and download availability.</p>

  <p>Ask Codex to handle your local scanner setup. <a href="./getting-started/agent-guided-setup/#codex-local-installation">Install MCP ZAP Connect locally</a>, then ask it to check prerequisites, start the Docker stack, configure your private MCP connection and verify status. The skill can help install missing prerequisites with your approval, then recheck and continue setup. Scans are a separate request.</p>

  <p>The capabilities below describe current source.</p>

  <ul class="capability-list">
    <li><strong>Scan_Tracking</strong>: Queue a crawl or active scan, then use its Operation ID to check progress or stop it. Both in-memory and PostgreSQL storage support this workflow.</li>
    <li><strong>Findings_Evidence</strong>: Read target-scoped findings, export snapshots, compare baselines and retrieve reports.</li>
    <li><strong>Operational_Guardrails</strong>: Enforce scopes, rate limits, correlation IDs, queue observability, and scan-history evidence.</li>
  </ul>
